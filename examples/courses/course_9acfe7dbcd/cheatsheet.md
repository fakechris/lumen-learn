# 泰勒展开：用多项式逼近函数 · 速查表
> ｜编译自课程包（概念图 / 要点 / 板书 / 误区），不含课堂之外的内容。

## 每节要点
**为什么要用多项式逼近函数？**
- **局部逼近** — 多项式简单，光滑函数复杂；用多项式在一点附近近似光滑函数，逼近是局部的，不是全局的。
**匹配导数构造泰勒多项式**
- **泰勒多项式** — 在 a 点匹配函数值与各阶导数，分母的 k! 抵消求导产生的倍数，复制局部形状。
**e^x 的麦克劳林展开：多项式逼近的威力**
- **e^x 的麦克劳林级数** — e^x = 1 + x + x²/2! + x³/3! + ⋯，对一切实数 x 收敛；x 越大只需更多项，精度照样能追上。
**sin x 的展开与小角度近似**
- **小角度近似** — sin x ≈ x 是麦克劳林级数的一阶截断，x 在约 10 度内误差可接受。
**ln(1+x) 的展开及其收敛域**
- **展开有边界** — 泰勒展开不是万能钥匙：e^x、sin x 处处收敛，ln(1+x) 只在 |x|<1 内有效。用前先查收敛域。
**余项：被丢掉的尾巴**
- **拉格朗日余项** — 余项 = 导数因子 × 距离因子，ξ 夹在 a 与 x 之间；它精确刻画截断误差，也决定收敛半径。
**为什么 ln(1+x) 的级数只在 |x|<1 收敛**
- **余项裁判** — 泰勒级数收不收敛，不看函数长什么样，看拉格朗日余项是否趋于零。余项趋于零的范围，就是收敛半径。

## 关键板书与公式
- 给定：光滑函数 $f$，点 $a$
- 找一个多项式 $p$
- 要求：在 $a$ **附近** $|p(x)-f(x)|$ 很小
- 注意：是 **附近**，不是处处
- 多项式：只有 **加法** 和 **乘法**
- 目标：在一点附近用多项式近似光滑函数
- 逼近是 **局部的**，不是全局的
- 下一步 → 怎么找系数？
- $p_0$：只匹配 $f(a)$ → 过点，方向不对
- $p_1$：再匹配 $f'(a)$ → 贴着切线
- $p_2$：再匹配 $f''(a)$ → 弯曲也同向
- 规律：**多匹配一阶，局部更像**
- 匹配到 $n$ 阶导数：
- $f(a) + f'(a)(x-a) + \frac{f''(a)}{2!}(x-a)^2 + \cdots + \frac{f^{(n)}(a)}{n!}(x-a)^n$
- 第 $k$ 项系数：$\frac{f^{(k)}(a)}{k!}$
- 为什么除 $k!$？→ 求 $k$ 次导会乘出 $k!$，除回去才等于 $f^{(k)}(a)$
- 设第 $k$ 项：$c_k (x-a)^k$
- 求 $k$ 次导 → 指数掉下来：$k \cdot (k-1) \cdots 1 = k!$
- 在 $a$ 点：这一项贡献 $c_k \cdot k!$
- 要它 $= f^{(k)}(a)$ → $c_k = \dfrac{f^{(k)}(a)}{k!}$
- 所以分母的 $k!$ 是**除回去**的
- 匹配 $f(a)$ → 过同一点
- 匹配 $f'(a)$ → 同斜率
- 匹配 $f''(a)$ → 同弯曲

## 常见误区（对的说法）
- 查表或者背过常用值：查表确实能查到，但表也是别人算好的，你还是不会自己算。
- 只能按计算器，没别的办法：计算器内部其实就是用加法和乘法算的，只是你不知道而已。
- 因为多项式可以无限逼近任何函数：能逼近是结果，不是原因——选它是因为它好算。
- 因为多项式次数高，什么都能表示：次数高不等于好算，而且高次多项式反而更难控制。
- 误差一直很小，到某个点突然崩掉：误差是连续增大的，不会突然跳变。
- 误差始终为零，因为 p 就是 sin 的近似：p(x)=x 只在原点附近近似，远处误差很大。
- 能，至少那个点对上了，附近应该差不多：这是最自然的直觉：以为抓住一个点就抓住了局部。但一个点只给了一个条件，斜率、弯曲都还没管。
- 多项式在 a 点附近越来越贴原函数：有人会担心条件越多越冲突，其实每多匹配一阶，只是把 a 点附近的形状锁得更紧。
- 没关系，反正多项式在 a 点的值还是对的：只盯着函数值，忽略了高阶导数的匹配——这正是典型误区。
- 不能，多项式只能在零附近像，远了就散架：这是最常见的直觉：以为多项式增长不够快，远处一定崩。其实项数足够多时，多项式可以一路贴住 e 的 x 次方。
- 还是差很远，多项式根本追不上指数：这是没动手之前的直觉：以为多项式增长太慢，远处永远追不上。拖一下滑块就会发现，项数够多时误差掉得很快。
- x 太大了，多项式根本追不上：这是典型误区：把“x 越大需要项数越多”误当成“x 大了就不收敛”。收敛和收敛快慢是两件事。
