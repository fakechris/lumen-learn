学生能解释两个非零不平行向量在三维空间中的张成是一个平面，并理解为什么不能张成整个三维空间。｜编译自课程包（概念图 / 要点 / 板书 / 误区），不含课堂之外的内容。

每节要点

两个向量能张成什么？

  • 张成 = 棍子能到的所有地方 — 两根不平行的棍子只能铺出一张过原点的纸（平面）。再多的棍子，只要都躺在纸上，纸还是纸；一根戳出纸面的棍子，才能把纸变成整个房间。维度数的是独立方向，不是向量个数。

关键板书与公式

  • $\vec{v}_3 = \vec{v}_1 + \vec{v}_2$ → 没有新方向
  • $\text{span}(\vec{v}_1, \vec{v}_2, \vec{v}_3) = \text{span}(\vec{v}_1, \vec{v}_2)$，线性相关
  • 换一根戳出纸面的 $\vec{u}$ → $\text{span}(\vec{v}_1, \vec{v}_2, \vec{u}) = \mathbb{R}^3$
  • 决定维度的：独立方向的个数，不是向量个数

常见误区（对的说法）

  • 能，c1 c2 随便调，总有一组行：这是最常见的直觉：以为两个参数可以自由到任何地方。但两个参数只能在一张纸上滑动，红球在纸的上方。
  • 能，多一根总比少一根强：以为向量数量多了维度就自动多了。可 v3 本来就是 v1、v2 拼出来的，它没带来新方向。
