# 简谐振动：弹簧上的物理直觉 · 速查表
> ｜编译自课程包（概念图 / 要点 / 板书 / 误区），不含课堂之外的内容。

## 每节要点
**从恢复力到简谐振动方程**
- **力决定运动的形式** — 线性恢复力 F=-kx 使加速度与位移反向正比，得到 d²x/dt²=-(k/m)x，其解即简谐振动。
**猜一个解：简谐振动通解**
- **简谐振动通解** — x(t)=A cos(ωt+φ)：ω 由系统定快慢，A 与 φ 由初始条件定大小和起点。
**相位：转过的角度与影子位置**
- **相位即角度** — 相位是圆周运动转过的角度，影子位置由它决定；相位差 0 同相，π 反相。
**弹簧振子的能量转换与守恒**
- **能量守恒** — 动能与势能此消彼长，总和恒为 1/2 kA^2，理想振子不漏能。
**周期由质量与刚度决定，与振幅无关**
- **周期只看 m 和 k** — T=2π√(m/k)：质量越大越慢，弹簧越硬越快，振幅只改能量不改周期。

## 关键板书与公式
- 平衡位置 $O$：弹簧自然长度处
- 右移 $x$ → 弹簧拉长
- 恢复力方向：**指向 $O$**
- 偏离朝右，受力朝左 → 方向相反
- 大小：$|F| = k|x|$
- 方向：与 $x$ 相反 → 加负号
- $F = -kx$
- $x>0$ → $F<0$
- $x<0$ → $F>0$
- 牛顿第二定律：$ma = F$
- 代入恢复力：$ma = -kx$
- 两边除以 $m$ → $a = -\frac{k}{m}x$
- 写成微分方程：$\frac{d^2x}{dt^2} = -\frac{k}{m}x$
- 线性恢复力：$F = -kx$
- 牛顿第二定律 → $a = -\frac{k}{m}x$
- 微分方程：$\frac{d^2x}{dt^2} = -\frac{k}{m}x$
- **线性恢复力 → 简谐振动**
- 两个解合起来 → $x(t) = A\cos(\omega t + \varphi)$
- $\omega = \sqrt{k/m}$
- $A$：振幅（最大偏移）
- $\omega$：角频率（每秒多少弧度）
- $\varphi$：初相（$t=0$ 时的起跑角度）
- 通解：$x(t) = A\cos(\omega t + \varphi)$
- $\omega = \sqrt{k/m}$ → **系统定快慢**

## 常见误区（对的说法）
- 弹簧一直往左拉，物块就一路加速冲过平衡位置跑掉：这是最常见的直觉：把弹簧的拉力当成方向不变的恒力，于是以为物块只会单向加速。
- 朝右，弹簧被拉长了当然继续往外拽：把弹簧想象成橡皮筋：以为拉长后它还想继续往外伸。其实弹簧被拉长时是往回缩的。
- 会，力一直拉着它，它只会越来越快：这是典型误区：以为弹簧的拉力方向不变，像恒力一样一直朝一个方向推。实际上位移一翻到另一边，力的方向也跟着翻。
- 指数函数，它求导还是自己，加个负号就行：指数函数求导还是自己，不会变号；要变号得是 e 的虚数次方，那其实就是正弦余弦。
- 够，sin 从零开始，弹簧一般就从零开始动：sin 只能描述从平衡位置出发的情况；如果一开始就把弹簧拉到最远处再松手，初始速度为零，sin 就描述不了。
- 波峰变高了，因为 φ 也是振幅的一部分：把 φ 和 A 混在一起，以为初相也管高度。
- 波动变快了，因为 φ 影响周期：把 φ 和 ω 混在一起，以为初相也管快慢。
- 匀速来回，跟质点转圈一样快慢不变：把影子当成独立的小球，以为它也匀速。其实影子的速度是圆周速度在 x 轴上的分量，转到两头时分量最小。
- 来回变快，幅度还是 A 不变：以为转得快影子就甩得更远。其实幅度由半径 A 决定，转速只改变影子来回的快慢。
- 一个在最右时，另一个也在最右：这是把同相和反相搞混了：相位差 π 意味着步调完全相反。
- 两样都很大，动能和势能一起达到最大：很多人以为端点处速度为零但动能还很大，其实动能跟速度平方挂钩，速度为零动能就是零。
- 先变长再变短，端点最长：有人以为越靠近端点动能越大，其实速度在减小，动能条只会越来越短。
