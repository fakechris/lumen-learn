# 极限求值：夹逼定理 · 速查表
> 学生能解释为什么 x²·sin(1/x) 在 x→0 时极限为 0，并说出夹逼定理的两个条件。｜编译自课程包（概念图 / 要点 / 板书 / 误区），不含课堂之外的内容。

## 每节要点
**极限求值：夹逼定理**
- **夹逼定理 = 三明治** — 算不出来的极限，找两片容易算的面包把它夹住；面包汇合在哪，馅料的极限就在哪。两个条件缺一不可：夹住，且汇合。

## 关键板书与公式
- 若 $g(x) \le f(x) \le h(x)$
- 且 $\lim g(x) = \lim h(x) = L$
- 则 $\lim f(x) = L$ → **馅料只能待在面包汇合处**

## 常见误区（对的说法）
- 它一直在震荡，所以极限不存在：震荡不等于发散：只要振幅被压到 0，震荡也会收敛。看读数，F(X) 的绝对值越来越小。
- 能，反正函数被夹住了：夹住只是第一个条件，第二个条件是两个界限的极限相等。没汇合就没结论。
