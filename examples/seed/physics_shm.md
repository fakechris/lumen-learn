# 简谐振动：弹簧上的物理直觉

## 力决定运动的形式
物体系在弹簧上，偏离平衡位置 $x$ 时受到恢复力 $F = -kx$（$k$ 是劲度系数，负号表示永远指向平衡位置）。
牛顿第二定律 $ma = -kx$ 给出微分方程：
$$\frac{d^2 x}{dt^2} = -\frac{k}{m}x$$

## 猜一个解
什么函数求两次导后变回自己的负数？正弦和余弦。
通解 $x(t) = A\cos(\omega t + \varphi)$，其中 $\omega = \sqrt{k/m}$。
三个参数各有名字：振幅 $A$（最大偏移）、角频率 $\omega$（每秒多少弧度）、初相 $\varphi$（$t=0$ 时的"起跑角度")。

## 相位是圆周运动在直线上的影子
把振动看作匀速圆周运动在横轴上的投影：质点转过的角度就是相位 $\omega t + \varphi$。
两个同频振动的"步调差"就是相位差 $\Delta\varphi$：同相（$\Delta\varphi = 0$）一起到最大，
反相（$\Delta\varphi = \pi$）一个在最左时另一个在最右。

## 能量在两种形式间来回
动能 $E_k = \frac{1}{2}mv^2$，弹性势能 $E_p = \frac{1}{2}kx^2$。
在平衡位置速度最大（动能峰值），在端点 $x = \pm A$ 速度为零（势能峰值），
总和 $E = \frac{1}{2}kA^2$ 恒定。周期 $T = 2\pi\sqrt{m/k}$：质量越大越慢，弹簧越硬越快，与振幅无关。
